# AndroidControlsDemo

This project contains a complete Android Studio demo app with the most common UI controls.

## Included controls
- TextView
- EditText
- Button
- ImageView
- CheckBox
- RadioButton / RadioGroup
- Spinner
- Switch
- SeekBar
- ProgressBar
- AlertDialog
- Toast

## Files created
- `settings.gradle.kts`
- `build.gradle.kts`
- `gradle.properties`
- `app/build.gradle.kts`
- `app/src/main/AndroidManifest.xml`
- `app/src/main/res/layout/activity_main.xml`
- `app/src/main/java/com/example/androidcontrols/MainActivity.kt`

## How to run in Android Studio
1. Open Android Studio.
2. Select `Open` and choose this project folder.
3. Let Gradle sync complete.
4. Connect an emulator or Android device.
5. Click **Run** to launch the app.

## Notes
- This project is set up for Kotlin.
- The app displays all controls in one screen and updates the status text when each control is used.
- If Android Studio prompts for Gradle or SDK setup, install the recommended components.
